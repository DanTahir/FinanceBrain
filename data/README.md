# FinanceBrain data (100% synthetic)

Everything in this folder is **fictional**. The firms (Halcyon Ridge Capital, Brightwater Credit Union), people,
clients, accounts, counterparties, deals, and every identifier (names, phones, emails, addresses, SSNs, account /
routing / card numbers, IBANs, SWIFT codes, EINs, salaries, medical notes) were generated by `datagen/` with Faker
and checksum-valid generators. None of it refers to a real person or organization.

| Path | Contents |
|---|---|
| `world/<tenant>/world.json` | Deterministic world model (org chart, systems, ownership history, clients, accounts, transactions, deals, channels) and storyline ground truth. Built by `python -m datagen.world`. |
| `gen_cache/<tenant>/*.json` | Raw LLM writer outputs. They contain **placeholders only** (e.g. `{{CLIENT_PHONE:c_0042}}`), never PII values: writers never see PII. |
| `raw/<tenant>/<kind>.jsonl` | Final corpus (slack, email, ticket, doc, meeting, crm), with placeholders filled locally by synthetic values. This is the input to the redaction + ingestion pipeline. |
| `raw/<tenant>/pii_spans.jsonl` | Ground truth for the redaction eval: every injected PII span (`doc_id`, `field`, `start`, `end`, `type`, `entity_id`, `value`). |
| `raw/<tenant>/ground_truth.json` | Storyline beat to document map, decision trail (pause, resume, supersedes), MNPI docs, planted leaks. |
| `raw/<tenant>/manifest.json` | Counts, live-feed split, PII span counts by type, generation stats, and LLM cost. |

Documents dated on or after 2026-10-01 have `live_feed: true` and are replayed through the live pipeline in the demo.

Regenerate with `python -m datagen.generate --tenant <tenant>`. It reuses `gen_cache`, so a regeneration makes no
LLM calls. Verify with `python scripts/verify_corpus.py`.
